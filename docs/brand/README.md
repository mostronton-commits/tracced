## Кольори

Code Navy `#090D16` · мʼята `#A7F3D0` · чорнило `#0F172A` · фон `#F8FAFC` · лінії `#E2E8F0`.
Мʼята лишається кольором знака і статусів, не заливкою великих площин.

## Як користуватись

Мінімальний розмір знака — 16 пікселів; нижче ніжка зливається. Вільне поле навколо — не менше
висоти поперечини. Знак не обертати, не розтягувати, не додавати до нього текст усередині плитки:
назва завжди поруч, а не в ньому. На кольорових фонах — лише повністю мʼятний або повністю
чорнильний варіант, без напівтонів.

Геометрія: viewBox 64×64, товщина штриха 7, кінці круглі. Знак оптично центровано, тому в макетах
його можна ставити по геометричному центру плитки.
